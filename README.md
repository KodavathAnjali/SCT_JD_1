# SkillCraft Technology Internship - Task 1

## Project Title
Temperature Converter

## Description
This project is a Java-based Temperature Converter that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin. The program provides accurate conversions using standard temperature conversion formulas.

## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple console-based user interface
- Accurate temperature conversion formulas

## Technologies Used
- Java
- VS Code / Eclipse IDE

## How to Run
1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile and run the `TemperatureConverter.java` file.
4. Follow the on-screen instructions to perform temperature conversions.

## Learning Outcomes
- Understanding user input handling in Java
- Working with conditional statements and switch cases
- Implementing mathematical formulas
- Improving problem-solving skills
